## Overview

A fully responsive personal portfolio showcasing my experience as a Linux Engineer, my projects in cybersecurity and infrastructure, and my transition into a cybersecurity-focused engineering role. Built for performance and clean design across all devices — mobile, tablet, desktop, and wide screens.

---

## Features

- **Fully Responsive** — optimized for every screen size from 320px phones to 4K displays
- **Dark / Light Mode** — system-aware theme toggle
- **Animated Sections** — smooth slide-in animations on scroll
- **Contact Section** — "Let's talk?" footer with interactive cursor dot
- **Mobile Navigation** — portal-based hamburger menu with active page highlighting
- **Resume Download** — direct PDF download from the sidebar
- **Static Generation** — all pages statically generated by Next.js for fast load times

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Blur141/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm start
```

## Project Structure

```
app/
├── about/              # About page
│   └── page.tsx
├── components/
│   ├── global/         # Navbar, Footer, MobileMenu, ContactSection
│   ├── pages/          # WhatIDo, Job, Projects, Skills, Education, Certifications
│   └── shared/         # Social links
├── data/
│   └── portfolio.ts    # All content — edit this to update the site
├── animation/          # Slide animation wrapper
├── font/               # Custom fonts
├── icons/              # HeroSvg and other SVG icons
├── styles/             # Global CSS
└── layout.tsx          # Root layout with Navbar + Footer
```

> **To update content**, edit `app/data/portfolio.ts` — all profile info, jobs, projects, skills, education, and certifications are defined there.

## Deployment

The site is deployed on **Vercel**. Any push to the `main` branch triggers an automatic deployment.

To deploy your own fork:

1. Fork this repository
2. Go to [vercel.com](https://vercel.com) and import the repo
3. Vercel auto-detects Next.js — no configuration needed
4. Click **Deploy**
